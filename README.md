# 🤖 AI Assistant Pro

A modern, feature-rich AI chatbot application powered by OpenRouter API with a sleek WhatsApp/iMessage-style bubble chat interface.

## ✨ Features

### 🎨 **Modern UI/UX**
- **Bubble Chat Design**: WhatsApp/iMessage-style message bubbles
- **True Dark Night Mode**: Pure black backgrounds for better contrast
- **Responsive Design**: Perfect on desktop, tablet, and mobile
- **Clean Layout**: Minimalist design with organized sidebar

### 🤖 **AI Integration**
- **OpenRouter API**: Multiple AI model support
- **Horizon Beta Model**: Free tier with excellent performance
- **Real-time Responses**: Fast AI message generation
- **Typing Indicators**: Live typing animation

### 💬 **Chat Features**
- **Message Copy**: Copy any message with one click
- **Chat History**: Persistent conversation storage
- **Message Search**: Find messages across all chats
- **Export Chat**: Download conversations as JSON
- **Multiple Chats**: Create and manage multiple conversations

### 🔧 **Advanced Features**
- **Code Syntax Highlighting**: Beautiful code block rendering
- **Voice Input**: Speech-to-text capability (mock)
- **File Upload**: Drag & drop support (mock)
- **Settings Panel**: Customize temperature, themes, models
- **Keyboard Shortcuts**: Quick navigation (Ctrl+N, Ctrl+/, Esc)
